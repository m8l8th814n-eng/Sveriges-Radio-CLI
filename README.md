# Sveriges Radio CLI
console program för sveriges radio skrivet i rust. 
![](https://github.com/m8l8th814n-eng/Sveriges-Radio-CLI/blob/main/2915.png)

  Så bygger du paketet:

cargo build


install:
  
  cd ~/SRTUI;
  sh dobin.sh && 
  makepkg -si


  Runtime-deps i paketet:

  - cava
  - ffmpeg
  - alsa-lib
  - glibc
